Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres una persona desarrolladora que acaba de incorporarse a Tailspin Toys, una empresa ficticia de financiación colectiva de juegos de mesa con temática de desarrollo. El backlog del equipo ya está registrado como incidencias de GitHub y está listo para que elijas una. Incluye trabajo de funcionalidades, como filtrado y paginación, además de mejoras de calidad, como accesibilidad y estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller comienza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente agéntico en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, skills, agentes personalizados, Playwright MCP, Agent Merge y comandos de barra útiles.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia de modo de sesión, colabora en Canvas y gestiona incidencias y solicitudes de incorporación de cambios de GitHub en la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, orienta su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abra.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
